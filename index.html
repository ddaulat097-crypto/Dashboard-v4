ⓘ How this analysis works
Pivot-based swing detection. BOS = break of prior swing; CHoCH = reversal. FVG = 3-bar imbalance. OB = last opposite candle before ≥0.5% displacement. Delta divergence compares CVD at successive swing extremes — CVD approximated from close-position-in-range (no tape data). Absorption flags bars with vol ≥1.8x avg and range ≤0.7x avg. Candlestick patterns weighted by context — pin bar at a liquidity sweep scores higher than pin bar alone. All from real OHLCV. Confluence is interpretive, not signals. Verify before trading.

🤖 AI Second Opinion
Independent reasoning check on the app's own signal

Powers the "AI Second Opinion" button on the Summary tab. Get a key at console.anthropic.com. Stored only in this browser, sent only to Anthropic's API when you tap the button. Each analysis costs roughly 1–3 cents.

What it does: packages the app's current verdict, ratio, HTF score, structure, open FVGs, order blocks, liquidity levels, cross-asset confluence, divergences, recent verdict-log history, and paper-trade record, then asks Claude for a fast color-coded read — green = supportive, yellow = mixed, red = contradictory — with full detail on tap. News search: when on, it searches live Nasdaq-affecting headlines (Fed, econ data, mega-caps) and folds them in. What it still can't see: $TICK/breadth, order flow. It names those as a checklist rather than guessing. The app's signal stays primary; a red read means "look closer," not "don't trade."

Auto (recommended): clean setups use Haiku (cheapest, ~0.3¢), conflicted ones auto-escalate to Sonnet for a sharper read. Or pin a model: Haiku fastest/cheapest, Sonnet best balance (~1¢), Opus deepest reasoning (~1.5¢, marginal for this task). Search adds ~1¢/tap on top regardless.

ON: the AI searches live Nasdaq news as part of the read (~1.5–3¢/tap; search is billed ~1¢ each). OFF: faster logic-only check (under 0.2¢/tap). Default ON.

The model is now auto-routed: clean low-conflict setups use Haiku (cheapest), while setups with internal conflict (HTF fighting the verdict, divergences, recent losses, M8 disagreeing) auto-escalate to Sonnet for a sharper read. The payload is also sent in a compact form that's ~40% smaller than before with no loss of analytical detail. Force one model via the tape_ai_model key if you prefer.
